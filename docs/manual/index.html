PTS Manual

Everything you need to build, set up and operate a five-mount PTS camera system.

PTS is a five-mount motorised pan / tilt / slider / zoom camera system for live video production. This manual is organised so you can start at the top and work down for a first build, or jump straight to a topic.

New to PTS? Start with Getting started — it takes you from powering on to your first camera move.
