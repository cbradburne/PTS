Web app

Full control from any phone on the hub's WiFi — nothing to install.

The hub serves a web app straight from its own flash. Any phone, tablet or laptop that joins the CamMount WiFi can open it in a browser and control the rig — no app store, no install, no PC.

Getting on

  1. Join the CamMount WiFi network.
  2. Open a browser to http://192.168.4.1.
  3. The web app loads and connects to the hub over WebSocket automatically.
Make it one tap Add the page to your phone's home screen and it opens like an app. Several phones can be connected at once — each one sees the same live state.

What you can do

  • Recall and store positions — the full ten slots per camera (Storing & recalling shots).
  • Jog pan, tilt, slider and zoom.
  • Set speed presets per camera.
  • Look-at — pick a subject and run ◀ / ▶ moves (Look-at tracking).
  • Manage pairing — the Mounts page shows the hub's live pairing table, forgets a retired mount, and resolves same-number conflicts (Replace / Ignore) — so a hub plus a phone is a complete rig (Pairing & identity).

The layout adapts to portrait and landscape, so it's usable held either way.

Live hand-off The web app is a peer of every other surface — a shot recalled here lights up on the PC app and the console too, and you can start a move on your phone and finish it on the desk. State lives on the mounts, so controllers come and go freely (How it fits together).
Safety Jogs from the web app are re-streamed at 20 Hz by the hub; if your phone drops off the WiFi mid-jog, the mount's dead-man stops it within half a second. E-STOP is always one tap away.
