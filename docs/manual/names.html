Camera & position names

Name the cameras and their position slots once, and every PC app and phone on the rig shows the same names.

By default a camera is "Cam 1" and a slot is just a number. Name each camera and each of its 10 position slots — "Cam 2" becomes "Stage Left" and slot 3 becomes "Lectern". Names are display labels only; they don't change any camera behaviour.

The hub keeps the names Every PC app and every phone shows the names the hub holds. Rename a shot on your phone and the PC app shows the new name a moment later, and the other way round. They are saved on the hub, so they survive a restart of anything. (Before September 2026 each device kept its own; see Older hub firmware.)

Editing a name

  • PC app — press Edit, then tap a camera button to rename the camera, or a position to rename that shot.
  • Phone or tablet — tap EDIT, then tap a camera button to rename the camera (in the extended view, a row's name at the left does the same), or a position to rename that shot.

Clear a camera's name to put it back to "Cam 1". A position's name shows while that position holds a shot. Clearing a position clears its name too, whichever device cleared it — the PC app, a phone or the hub's screen — so the next shot stored there doesn't inherit a name that described the last one.

A name can be up to 20 bytes: 20 letters of plain text, fewer with accents or other alphabets. Anything longer is shortened, at the end of a whole letter.

Save and load sets

For a set of names per production, use Config → Camera & Position Names in the PC app.

ButtonWhat it does
Save…Writes the current names to a .json file you choose, in Documents/PTS.
Load…Sends a saved set to the hub, which gives it to every device. It asks first, because it replaces everyone's names.
Per-show name sets Set up naming for a production once, Save… it as e.g. Autumn-Gala.json, and next time just Load… it.

Moving to the hub

The first time a PC app meets a hub that keeps names, and that hub has none yet, the PC sends it the names it was showing — so the names you had carry over the day the hub is updated. A phone does the same with any names it had kept itself, then forgets its own copy. This happens once per device, and never over names the hub already has.

More cameras, different screens

The hub keeps names for up to 32 cameras, by camera number. Each device asks for the names of the cameras it shows, so two screens showing different cameras each get their own, from the same place.

Older hub firmware

If the hub's firmware predates shared names, the PC app notices within 15 seconds and keeps the names itself, as it always did: it opens with Default.json, edits go to a working copy (temp.json), and Set as Defaults appears in Config to choose the startup set. The box in Config says which way it is working.
